### 2. Neural Network Basics
- **Neuron:** a circular unit with an input side and an output side. Inputs go in, processing happens inside, and a transformed output comes out. The instructor compared this to the nucleus and dendrites in biology.
- **Network:** a mesh-like collection of interconnected neurons.
- **Layers:**
  - **Input layer:** one per network. Receives the input features X1, X2, X3, and so on.
  - **Hidden layer(s):** one or more. The number of hidden layers and neurons per layer can vary.
  - **Output layer:** one per network. Produces the predicted output, written as **Ŷ (Y-hat)**.
- **Example architectures discussed:**
  - 5 input neurons, 3 output neurons, and 2 hidden layers.
  - 5 inputs, 2 outputs, and 2 hidden layers (8 neurons in the first hidden layer and 10 in the second).
- Every neuron in one layer is connected to every neuron in the next layer.

### 3. Error (Loss)
- Error is measured by comparing the actual value Y with the predicted value Ŷ.
- The instructor wrote this as a sum over all data points: Σ (Y − Ŷ)².
- The goal is to keep the error as small as possible. The instructor called this "loss" as well.

### 4. Forward and Backward Propagation
- **Forward propagation:** moves from the input layer, through the hidden layers, to the output layer. The result is the predicted output Ŷ.
- **Backward propagation:** if the prediction is not good enough, the network moves back from the output layer to the input layer and adjusts the weights.
- **Weights:**
  - The input data itself is never changed, because it belongs to the client.
  - Instead, the weight attached to each input feature is changed. This increases the importance of useful features and reduces the importance of less useful ones.
  - Weight update rule shown:
    - W_new = W_old − α × (∂Loss / ∂W)
    - α (alpha) is the learning rate.
    - ∂ is the partial derivative. The instructor said the full math involves calculus and skipped it.
- **Student analogy:** a school student plans study, play, and sleep before an exam. Study should get the most weight, followed by sleep. This was used to show why weights matter.
- **Epoch:** one forward propagation plus one backward propagation. Training usually needs many epochs (for example 10, 20, or 30).
- The instructor said weights are "probabilistic" and range between 0 and 1. See the Gaps section.

### 5. Activation Functions
- Purpose: help extract linear and non-linear patterns from the data. The first part of a neuron computes the weighted sum. The second part applies the activation function.
- Activation functions named: **Sigmoid**, **Tanh** (hyperbolic tangent; transcribed as "10 hyperbolic"), **Softmax**, and **ReLU** (Rectified Linear Unit).
- Usage, as stated by the instructor:

| Function | Stated use | Where it is applied |
|---|---|---|
| Sigmoid | Binary classification | Output layer |
| Tanh | Mostly hidden layers (also said to be used for binary classification) | Hidden layers |
| Softmax | Multi-class classification | Output layer |
| ReLU | Regression (not for classification) | Hidden and/or output layer |

- **Scenario exercise** (participants were asked to choose the output activation function in the chat):
  1. **Customer churn** (will the customer stay or leave?): binary classification, so Sigmoid.
  2. **Sentiment analysis** (positive, negative, or neutral): multi-class, so Softmax.
  3. **House price prediction:** a numeric value, so regression and ReLU.

3. **Pixel extraction:** pixels are the building blocks of an image. Values range from 0 (black) to 255 (white).

5. **Feature map:** the normalized matrix.

### 8. Convolution Operation
- A **filter** (also called a **kernel**) is a small matrix, here 3 × 3, that slides over the feature map.
- At each position, the filter values are multiplied with the overlapping feature-map values and then summed.
- The filter is always smaller than the feature map so that it can traverse the entire map.
- Worked example: the first position produced 2, the next 1, and the next 0. The filter values were partly garbled in the transcript, so the exact numbers may not be reliable.
- **Output size formula:** Output = N − F + 1
  - N = input size (5), F = filter size (3)
  - Output = 5 − 3 + 1 = 3, giving a 3 × 3 output. The result has 9 values instead of 25.
- The output of the convolution is also a feature map.
