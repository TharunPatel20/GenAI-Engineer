## Sub-Topics and Details

### 1. RAG Pipeline Recap
- Data ingestion: load a PDF, web page, or Excel file.
- Chunking: split the text into smaller pieces.
- Embeddings: convert each chunk into a vector.
- Vector database: store the embeddings. Vector databases named: FAISS (transcribed "spice"), Pinecone, and Chroma.
- Query embedding: convert the user's question into a vector.
- Similarity search: find the stored vectors closest to the query. Augmentation then produces a user-friendly answer.

### 4. Limitations of Basic (Vanilla) RAG
- **Retrieval, but no prioritization:** RAG retrieves candidates but does not rank them by quality on its own. Similarity search with scores is one way to rank.
- **Keyword-dependent domains:** in fields such as healthcare, prescription and medicine names must match exactly. A GST number must also match exactly. Keyword search handles these cases.
- **Semantic search:** matches on meaning using vectors.
- **Hybrid search:** combines keyword and semantic search to improve retrieval quality.
- **BM25 (Best Matching 25):** a keyword-ranking technique named in the session.
- The instructor said these would be covered in more depth later, including in a practical demonstration.
