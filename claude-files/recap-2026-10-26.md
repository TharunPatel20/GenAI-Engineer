### 6. Five-Step Workflow for Supervised ML
1. **Gather data:** the data is raw. It may come from web scraping, surveys, campaigns, or clients. Raw data may contain redundancies, missing values, and irregularities.
2. **Preprocess data (data cleaning):** convert raw data into clean data. Feature engineering is part of this step.
3. **Exploratory Data Analysis (EDA):** analyze and visualize the clean data using NumPy, Pandas, Matplotlib, and Seaborn. The instructor said this is the same work as in the previous session.
4. **Divide the data:**
   - Independent features (inputs) are called **X**.
   - The dependent feature (output or target) is called **Y**.
5. **Split the data:**
   - **Training set:** used for the model to learn patterns (most of the data, for example 80%).
   - **Testing set:** used for evaluation (for example 20%).
   - After evaluation, check accuracy. If accuracy is poor, retrain the model.
