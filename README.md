# Next Gen AI Engineer, Cohort 4: Study Repository

> **New here? Start with [START-HERE.md](START-HERE.md).** It explains the learning path, how to open each project in Google Colab, and how to set your Gemini API key safely.

This repository holds the study materials for the 100 Next Gen AI Engineers program (Cohort 4). It collects the Zoom session transcripts, the per-session recap notes, the course schedule, and a detailed study guide that covers each schedule topic.

## Topics Covered

- Python Foundations (prerequisite refresher): Python basics, data structures, functions, NumPy (Numerical Python), Pandas, and Matplotlib
- Intro to Machine Learning (ML) and Deep Learning (DL): ML types and algorithms (regression, decision trees), train/validation/test splits, overfitting, neural networks, backpropagation, and activation functions
- Deep Learning Architectures and Transformer Basics: Convolutional Neural Networks (CNN), Recurrent Neural Networks (RNN), Long Short-Term Memory (LSTM), and the Transformer (self-attention, multi-head attention, positional encoding)
- ML vs. DL and the build-up to Large Language Models (LLMs)
- LLMs, Prompt Engineering, and Fine-Tuning: LLM evolution, tokenization, embeddings, context window, zero-shot, few-shot, and chain-of-thought prompting, Parameter-Efficient Fine-Tuning (PEFT), Low-Rank Adaptation (LoRA), and Quantized LoRA (QLoRA)
- Retrieval-Augmented Generation (RAG) Architecture, Fundamentals: document loaders, chunking, embeddings, vector stores, retrieval, generation, and the "lost in the middle" problem
- RAG Architecture, Advanced: hybrid retrieval (Best Matching 25, BM25, combined with vector search), query rewriting, rerankers, and evaluation (retrieval hit rate, groundedness, hallucination checks)
- LLMs vs. RAG, grounding, and the build-up to Agentic AI
- Agentic AI Introduction: autonomy, planning, tool use, single-agent vs. multi-agent systems, memory, and feedback loops
- Agentic AI and Future Directions: CrewAI, LangGraph, Model Context Protocol (MCP), guardrails, observability, graph databases, and reinforcement learning for decision-making
- AI Assurance and Governance: responsible AI, risk management, bias and fairness, explainability, the EU AI Act, and the NIST AI Risk Management Framework (RMF)
- Safety, Fairness, and Use Cases (discussion)
- Final Showcase: project presentations, Q&A, and a final project to build a full AI application
